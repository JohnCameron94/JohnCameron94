## ⚙️ Backend & Infrastructure

### Node.js REST API
- **Created and maintained** the RodeoReady **Node.js / Express** backend, serving as the core RESTful API for both web and mobile clients.
- Designed clean, well-documented API endpoints and maintained **Swagger API documentation** for internal and external consumers.
- Implemented authentication and authorization middleware to secure API routes.

### GraphQL API (AppSync)
- **Designed and maintained** the **AWS AppSync** GraphQL API, enabling efficient, flexible data querying from frontend clients.
- Defined and managed GraphQL schemas, resolvers, and subscriptions for real-time data capabilities.
- Leveraged **DynamoDB** as the primary NoSQL data store, optimizing access patterns for performance.

### Database Design
- **Designed and maintained SQL schemas** (MySQL) for relational data requirements.
- **Architected and maintained NoSQL data models** (DynamoDB) with careful attention to access patterns and partition key design.
- Performed schema migrations and optimized queries to support evolving product requirements.

### AWS Serverless Architecture
- **Architected and deployed** the full AWS Serverless backend — including **Lambda**, **API Gateway**, **AppSync**, **DynamoDB**, **SNS**, and **SQS**.
- Leveraged **AWS Amplify** to streamline frontend-backend integration and manage environment configurations.
- **Managed AWS account user access** using the principle of least privilege, ensuring secure, role-appropriate access across the engineering team.

### WebSocket — Non-Blocking Async Processing
- **Architected and implemented** a real-time, non-blocking asynchronous communication layer using **WebSocket**, enabling live data updates for time-sensitive rodeo event information.
- Designed the system to handle concurrent connections gracefully and scale under load.
